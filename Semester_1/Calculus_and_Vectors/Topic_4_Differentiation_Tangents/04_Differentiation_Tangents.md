## 📑 Key Formulas
*   **Power Rule:** `d/dx [xⁿ] = nxⁿ⁻¹`
*   **Product Rule:** `(uv)' = u'v + uv'`
*   **Quotient Rule:** `(u/v)' = (u'v - uv') / v²`
*   **Tangent Line Equation:** `y - y₁ = m(x - x₁)` where `m = f'(x₁)`.

## 🛠️ Practice These Problems
1.  Find the derivative of `f(x) = (x³ + 2x) / (x - 1)`.
2.  Find the slope of the tangent to `y = x²` at `x = 3`.
3.  Write the full equation of the tangent line for `y = √x` at `x = 4`.

---
> **💡 Pro Tip:** Before using the Quotient Rule, check if you can simplify the function first. Sometimes a little algebra saves a lot of calculus!
