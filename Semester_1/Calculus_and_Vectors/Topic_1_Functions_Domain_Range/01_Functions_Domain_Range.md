# 🧮 Topic 1: Functions, Domain & Range (Week 1)

This topic is the foundation of calculus. You must be able to identify where a function is "legal" (Domain).

## 📑 Key Concepts
*   **Domain:** All possible x-values (inputs).
*   **Range:** All possible y-values (outputs).
*   **Indeterminate forms to avoid in Domain:**
    *   Division by zero: `Denominator ≠ 0`
    *   Square root of negative: `Expression inside √ ≥ 0`

## 🛠️ Practice These Problems
1.  Find the domain of `f(x) = 1 / (x - 3)`.
2.  Find the range of `g(x) = x² + 4`.
3.  Illustrate the "Vertical Line Test" to determine if a graph is a function.

---
> **💡 Pro Tip:** When finding the Domain of a fraction with a square root in the denominator, remember that the value inside must be **strictly greater than zero** (not equal to zero!).
