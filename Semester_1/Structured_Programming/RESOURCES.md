# 💻 Structured Programming: Reference Guide & Study Resources

This resources directory aligns your C programming syllabus (Weeks 1 to 5) with elite global tutorials, high-yield Bengali video channels, and real university sessional code repositories.

---

## 📅 Weekly Syllabus Alignment & Resource Map

### 🔹 Weeks 1 & 2: Introduction to Programming & paradigms
*Syllabus Topics: History of programming, algorithm development, programming styles, language classification, compilers/translators, and paradigm classifications (structured, procedural, OOP).*

*   **Global Classrooms:**
    *   **[Harvard CS50 - Week 0 (Computational Thinking) & Week 1 (C)](https://cs50.harvard.edu/x/2024/weeks/1/):** Unbeatable introduction to compiler structures, machine code compilation (clang), IDE setup, and programmatic logic.
    *   **[Neso Academy - C Programming Playlist](https://www.youtube.com/playlist?list=PLBlnK6fEyqRggZZgYpPMUxdY1CYkZtXYZ):** Extremely clear explanations of computer language translators (Assemblers, Interpreters, Compilers) and C program structure.
*   **Vernacular Bangla Explanations:**
    *   **[Stack Learner - C Programming for Beginners](https://www.youtube.com/playlist?list=PL_XxuZqN0xVApC6_z0g9V1Z_9m7qC7C5u):** Outstanding explanation of memory concepts, compilation lifecycles, and setting up a GCC compiler locally in Windows.

---

### 🔹 Weeks 3 & 4: C Syntax & Data Management
*Syllabus Topics: C program structure, identifiers, keywords, data types, variable declarations, expressions, operators, library functions, and basic I/O functions.*

*   **Global References:**
    *   **[W3Schools C Tutorials](https://www.w3schools.com/c/):** Immediate, interactive browser-based playground to test variable scope, formatting specifiers (`%d`, `%f`, `%c`), and operator precedence.
    *   **[GeeksforGeeks C Programming Language Portal](https://www.geeksforgeeks.org/c-programming-language/):** Thorough, text-based guides detailing C identifiers, keywords, and library headers (`<stdio.h>`, `<math.h>`, `<string.h>`).
*   **Vernacular Bangla Explanations:**
    *   **[Learn with Sumit - Think in a Programming Way](https://www.youtube.com/@LearnwithSumit):** Concepts of algorithmic variable declarations and expressions explained with real-world software logic.

---

### 🔹 Week 5: Control Structures, Loops, and Functions
*Syllabus Topics: Control flows (if-else, nested switch), iterative loops (for, while, do-while), function definitions, parameter passing (call-by-value vs. call-by-reference), and basic pointer concepts.*

*   **Global Masters:**
    *   **[MyCodeSchool - Pointers in C/C++](https://www.youtube.com/playlist?list=PL2_aWCzGMAwLZp6LMUKI3cc7pgGsasm2_):** The absolute world-standard playlist for visualizing heap vs. stack memory allocation, pointer arithmetic, and reference-passing in C.
    *   **[TheAlgorithms/C GitHub Repository](https://github.com/TheAlgorithms/C):** Clean, raw C source code demonstrating standard algorithmic patterns, mathematical models, and basic sorting/searching arrays.
*   **Vernacular Bangla Explanations:**
    *   **[HM Nayem - Full-Stack Army Arrays & Functions Series](https://twinklecats.thinkific.com/):** High-yield series highlighting standard array manipulation pitfalls, multi-dimensional loops, and memory address dereferencing.

## 🎯 Active Recall & Programming Practice Arenas

Use these platforms to apply the "Boss Rush" (Error-Driven) study methodology. Test your limits by solving problems, triggering compiler errors, and fixing them.

1.  **[Codeforces - Junior Practice](https://codeforces.com/):**
    *   *Action:* Register and attempt Division 3 (Div. 3) or Division 4 contest problem sets. Start with "Problem A" files to build syntax confidence.
2.  **[LeetCode - Easy/Medium Track](https://leetcode.com/):**
    *   *Action:* Select the "C Language" filter and filter by "Arrays" and "Two Pointers" to practice C control structures under pressure.
3.  **[Bangladesh Competitive Programming Society (BCS) Discord Server](https://discord.com/invite/bangladesh-cp-server-bcs-powered-by-orbitax-816054133999665272):**
    *   *Action:* Participate in daily chat rooms where BUET and DU competitive programmers collaborate on solving algorithmic edge cases.
